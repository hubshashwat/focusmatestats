Your Data is Private

We believe your productivity data belongs to you. Here is how we guarantee your privacy:

  • Client-Side Only Execution This application runs entirely inside your web browser. No code runs on a backend server.
  • Direct Connection When you enter your API key, your browser connects directly to api.focusmate.com. There is no middleman server.
  • Zero Data Retention We do not have a database. Once you close this tab, your API key and session data are wiped from memory.
  • Open Source The code for this tool is public. You can verify exactly what it does.
